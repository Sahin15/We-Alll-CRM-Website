We ALLL Logo Generator

This page shows how the We ALLL logo should look. To use it in the PDF:

  1. Take a screenshot of the logo below
  2. Save it as we-alll-logo.png
  3. Place it in the backend/uploads/ directory
  4. The PDF generator will automatically use this logo

Alternative: You can also save the original colorful We ALLL logo image you have as we-alll-logo.png in the uploads folder.
